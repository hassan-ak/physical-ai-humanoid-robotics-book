### Isaac ROS VSLAM (Visual Simultaneous Localization and Mapping)

Visual SLAM is a critical capability for mobile robots that enables them to build a map of their environment while simultaneously determining their location within that map. Isaac ROS provides several VSLAM algorithms optimized for NVIDIA hardware.

#### ORB-SLAM in Isaac ROS

ORB-SLAM is a popular feature-based SLAM algorithm that works well with Isaac ROS. It uses Oriented FAST and Rotated BRIEF features to create robust maps.
