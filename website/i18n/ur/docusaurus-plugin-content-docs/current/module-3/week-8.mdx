## USD اور مصنوعی ڈیٹا کا تعارف اسٹارٹ اپ کے نقطہ نظر سے

اس ہفتے میں، ہم یونیورسل سین ڈیسکرپشن (USD) اور مصنوعی ڈیٹا جنریشن کے بنیادیات کا جائزہ لیں گے جس میں NVIDIA Isaac Sim کا استعمال کیا جاتا ہے۔ USD 3D منظر کے تبادلے کے لیے ایک طاقتور ڈھانچہ ہے جو کمپلکس سین کمپوزیشن اور اثاثہ مینجمنٹ کے قابل ہے۔ مصنوعی ڈیٹا جنریشن AI نظام کو تربیت دینے کے لیے اہم ہے تاکہ واقعی دنیا کے ڈیٹا کو جمع کرنے کی ضرورت کم ہو سکے۔

### یونیورسل سین ڈیسکرپشن (USD)

یونیورسل سین ڈیسکرپشن (USD) Pixar کا ایک طاقتور، توسیع پذیر ڈھانچہ ہے جو 3D منظر کے تبادلے کے لیے ہے۔ روبوٹکس اور AI کے تناظر میں، USD پیچیدہ محاورہ کی تخلیق کے قابل ہے جس کا استعمال AI نظام کو تربیت اور ٹیسٹنگ کے لیے کیا جا سکتا ہے۔

#### USD کے بنیادیات

USD ڈیٹا کو ایک سلسلہ وار نام کی جگہ کے میں منظرنامہ کی وضاحت کے لیے بنیادی اجزاء کا استعمال کرتا ہے جنہیں "prims" کہا جاتا ہے۔ یہ prims خصوصیات، متغیرات، اور روابط پر مشتمل ہو سکتے ہیں جو منظر کو بیان کرتے ہیں۔

```python
# Isaac Sim Python API مثال کے لیے USD prim کی تخلیق
import omni.usd
from pxr import Usd, UsdGeom, Gf

# موجودہ USD اسٹیج حاصل کریں
stage = omni.usd.get_context().get_stage()

# ایک نیا Xform prim تخلیق کریں
xform_prim = UsdGeom.Xform.Define(stage, "/World/Robot")

# Xform میں ایک میش شامل کریں
mesh_prim = UsdGeom.Mesh.Define(stage, "/World/Robot/Mesh")
mesh_prim.CreatePointsAttr([(0, 0, 0), (1, 0, 0), (0, 1, 0)])
```

### Isaac Sim میں RTX رینڈرنگ

RTX رینڈرنگ Isaac Sim میں NVIDIA کی RTX ٹیکنالوجی کا استعمال کرتے ہوئے فوٹو ریل اسٹک رینڈرنگ کی سہولت فراہم کرتا ہے۔ یہ مصنوعی ڈیٹا جنریٹ کرنے کے لیے اہم ہے جو حقیقی دنیا کی تصاویر سے مماثل ہو، جو کہ احساس کے نظام کی تربیت کے لیے بہت قیمتی ہے۔

#### RTX رینڈرنگ کا سیٹ اپ

Isaac Sim NVIDIA Omniverse کا استعمال RTX رینڈرنگ کے لیے کرتا ہے۔ رینڈرنگ پائپ لائن میں فزکلی بے سیسڈ میٹریلز، لائٹنگ، اور گلوبل ایلیومنیشن ایفیکٹس شامل ہیں۔

import omni.kit.commands
from omni.isaac.core.utils.stage import add_reference_to_stage

omni.kit.commands.execute("ChangeRenderer", renderer_name="RayTracedLightMap")

### مصنوعی ڈیٹا جنریشن

مصنوعی ڈیٹا جنریشن ایک ایسے ڈیٹا کو تخلیق کرنے کی عمل ہے جو حقیقی دنیا کے مشاہدات کی نقل کرتا ہے۔ روبوٹکس میں، یہ خاص طور پر احساس کے نظام کی تربیت کے لیے مفید ہے جس کے لیے مہنگے حقیقی دنیا کے ڈیٹا جمع کرنے کے مہمات کی ضرورت نہیں ہوتی۔

#### ڈومین رینڈمائزیشن

ڈومین رینڈمائزیشن ایک ایسی تکنیک ہے جو نیورل نیٹ ورک کو تبدیلی کے خلاف مضبوط بناتی ہے جو مصنوعی اور حقیقی ڈیٹا کے درمیان ہوتی ہے۔ تربیت کے دوران ماحولیاتی پیرامیٹر (لائٹنگ، ٹیکسچر، رنگ) کو متغیر کرکے، نیٹ ورک اہم خصوصیات پر توجہ مرکوز کرنا سیکھتا ہے۔

```python
# Isaac Sim Python API مثال کے لیے ڈومین رینڈمائزیشن
import omni.replicator.core as rep

# متغیر کے دائرے کی وضاحت کریں
with rep.new_layer():
    # لائٹنگ کو متغیر کریں
    lights = rep.get.light()
    with lights.randomize_position():
        rep.randomizer.uniform((0, 0, 5), (10, 10, 15))

    # میٹریلز کو متغیر کریں
    materials = rep.get.material()
    with materials.randomize_roughness():
        rep.randomizer.uniform(0.1, 0.9)

    # ٹیکسچرز کو متغیر کریں
    textures = rep.get.textures()
    with textures.randomize_diffuse_texture():
        rep.randomizer.augmentations.randomize_textures()
```

### ڈومین رینڈمائزیشن کی تکنیک برائے سیم-ٹو-ریئل ٹرانسفر

ڈومین رینڈمائزیشن ایک طاقتور تکنیک ہے جو نیورل نیٹ ورک کو تبدیلی کے خلاف مضبوط بناتی ہے جو مصنوعی اور حقیقی ڈیٹا کے درمیان ہوتی ہے۔ Isaac Sim میں، ڈومین رینڈمائزیشن کو Replicator ڈھانچے کے ذریعے لاگو کیا جا سکتا ہے، جو تربیتی ڈیٹا کی مصنوعی تخلیق کے لیے اہل ہے۔

#### Isaac Sim میں ڈومین رینڈمائزیشن کی لاگو کاری

```python
# Isaac Sim Python API مثال کے لیے ڈومین رینڈمائزیشن
import omni.replicator.core as rep

with rep.new_layer():
    # لائٹنگ کی حالت کو متغیر کریں
    lights = rep.get.light()
    with lights.randomize_position():
        rep.random.uniform((-10, -10, 5), (10, 10, 20))
    with lights.randomize_intensity():
        rep.random.uniform(100, 1000)
    with lights.randomize_color():
        rep.random.uniform((0.5, 0.5, 0.5), (1.0, 1.0, 1.0))

    # میٹریل کی خصوصیات کو متغیر کریں
    materials = rep.get.material()
    with materials.randomize_roughness():
        rep.random.uniform(0.1, 0.9)
    with materials.randomize_specular():
        rep.random.uniform(0.5, 1.0)
    with materials.randomize_albedo():
        rep.random.uniform((0.2, 0.2, 0.2), (1.0, 1.0, 1.0))

    # آبجیکٹ کے پوز کو متغیر کریں
    robots = rep.get.prim_by_path("/World/Robot")
    with robots.randomize_position():
        rep.random.uniform((-5, -5, 0), (5, 5, 0))
    with robots.randomize_rotation():
        rep.random.uniform((-180, -180, -180), (180, 180, 180))

    # کیمرے کی خصوصیات کو متغیر کریں
    cameras = rep.get.camera()
    with cameras.randomize_focal_length():
        rep.random.uniform(18, 50)
    with cameras.randomize_focus_distance():
        rep.random.uniform(10, 100)
```

یہ ڈومین رینڈمائزیشن کا نقطہ نظر تربیت کے دوران ماحولیاتی پیرامیٹر کو متغیر کرتا ہے، جس سے نیورل نیٹ ورک حقیقی دنیا کی حالت کے لیے بہتر ہو جاتے ہیں۔ لائٹنگ، ٹیکسچر، رنگ، اور آبجیکٹ کے مقام کو متغیر کرکے، حاصل شدہ AI ماڈل حقیقی دنیا کے انتظامات میں متغیرات کے لیے زیادہ مضبوط ہو جاتے ہیں۔

### Isaac Sim Python API کی مثالیں منظرنامہ کمپوزیشن کے لیے

منظرنامہ کمپوزیشن Isaac Sim میں متعدد آبجیکٹ، لائٹنگ، اور میٹریلز کے ساتھ پیچیدہ ماحول تخلیق کرنا شامل ہے۔ یہاں ایسے منظرنامے کمپوز کرنے کی مثالیں ہیں:

```python
# Isaac Sim Python API مثال کے لیے منظرنامہ کمپوزیشن
import omni
from omni.isaac.core import World
from omni.isaac.core.utils.stage import add_reference_to_stage
from omni.isaac.core.utils.prims import create_prim, get_prim_at_path
from omni.isaac.core.utils.semantics import add_semantics
import carb

# Isaac Sim کا آغاز
world = World(stage_units_in_meters=1.0)

# ایک زمین کا طول وجود میں لائیں
create_prim("/World/GroundPlane", "Mesh", position=[0, 0, 0], orientation=[0, 0, 0, 1])

# منظر میں ایک روبوٹ شامل کریں
# ایک حقیقی منظر میں، یہ روبوٹ USD فائل کا حوالہ دے گا
add_reference_to_stage(
    usd_path="path/to/robot.usd",
    prim_path="/World/Robot"
)

# ماحول میں مختلف آبجیکٹس تخلیق کریں
objects = [
    {"name": "box1", "position": [1.0, 0.0, 0.5]},
    {"name": "sphere1", "position": [-1.0, 0.5, 0.5]},
    {"name": "cylinder1", "position": [0.0, -1.0, 0.5]}
]

for obj in objects:
    create_prim(
        f"/World/{obj['name']}",
        "Cube" if "box" in obj['name'] else "Sphere" if "sphere" in obj['name'] else "Cylinder",
        position=obj['position']
    )

# تربیتی ڈیٹا کے لیے سیمینٹکس شامل کریں
for obj in objects:
    add_semantics(get_prim_at_path(f"/World/{obj['name']}"), "obstacle")

# منظر میں لائٹنگ شامل کریں
create_prim(
    "/World/Light",
    "DistantLight",
    position=[5.0, 5.0, 10.0],
    attributes={"color": (1.0, 1.0, 1.0), "intensity": 3000}
)

# تبدیلیاں لاگو کرنے کے لیے دنیا کو ری سیٹ کریں
world.reset()
carb.log_info("Isaac Sim منظرنامہ کمپوزیشن مکمل ہوئی")
```

### Isaac Sim میں RTX رینڈرنگ کا سیٹ اپ

Isaac Sim میں RTX رینڈرنگ NVIDIA کی RTX ٹیکنالوجی کا استعمال کرتے ہوئے فوٹو ریل اسٹک رینڈرنگ کی سہولت فراہم کرتا ہے۔ یہ مصنوعی ڈیٹا جنریٹ کرنے کے لیے اہم ہے جو حقیقی دنیا کی تصاویر سے مماثل ہو، جو کہ احساس کے نظام کی تربیت کے لیے بہت قیمتی ہے۔

```python
# Isaac Sim Python API مثال کے لیے RTX رینڈرنگ کا سیٹ اپ
import omni.kit.commands
from omni.isaac.core.utils.stage import add_reference_to_stage

# RTX رینڈرر فعال کریں (مناسب رینڈرر منتخب کریں)
renderer_settings = {
    "renderer": "RayTracedLightMap",  # اختیارات: "RayTracedLightMap", "HydraEarthExtDs", "KitOpenGL"
    "renderMode": "Render"  # اختیارات: "Render", "Wireframe", "Points"
}

# رینڈرر کی ترتیبات لاگو کریں
omni.kit.commands.execute(
    "ChangeRenderer",
    renderer_name=renderer_settings["renderer"]
)

# اعلی درجے کی رینڈرنگ کی ترتیبات کو تشکیل دیں
def setup_advanced_rendering():
    """Isaac Sim کے لیے اعلی درجے کی RTX رینڈرنگ کی ترتیبات کو تشکیل دیں"""

    # گلوبل ایلیومنیشن فعال کریں اگر دستیاب ہو
    carb.settings.get_settings().set_bool("/rtx/globalillumination/enabled", True)

    # تیز تر ت converging کے لیے ڈینوائزنگ فعال کریں
    carb.settings.get_settings().set_bool("/rtx/raytracing/denoise/enable", True)

    # اینٹی ایلیئسنگ تشکیل دیں
    carb.settings.get_settings().set_int("/app/antiAliasingMode", 8)  # 8x MSAA

    # کارکردگی کے لیے ملٹی ریزولوشن شیڈنگ
    carb.settings.get_settings().set_bool("/app/multiResolutionShading/enabled", True)

    carb.log_info("اعلی RTX رینڈرنگ کی ترتیبات تشکیل دی گئیں")

setup_advanced_rendering()

# فوٹو ریل اسٹک رینڈرنگ کے لیے کیمرہ تشکیل دیں
def setup_camera_for_rtx():
    """RTX رینڈرنگ کے لیے کیمرہ کی خصوصیات کو تشکیل دیں"""
    from omni.isaac.core.utils.prims import create_prim

    # ایک کیمرہ تشکیل دیں جس میں حقیقی خصوصیات ہوں
    create_prim(
        "/World/Camera",
        "Camera",
        position=[2.0, 0.0, 1.5],
        orientation=[0.0, 0.0, 0.0, 1.0]
    )

    # کیمرہ کی انٹرنسکس کو تشکیل دیں
    camera_prim = get_prim_at_path("/World/Camera")
    camera_prim.GetAttribute("focalLength").Set(24.0)  # 24mm فوکل لمبائی
    camera_prim.GetAttribute("horizontalAperture").Set(36.0)  # فل فریم
    camera_prim.GetAttribute("verticalAperture").Set(24.0)

    carb.log_info("RTX-کے لیے کیمرہ کا سیٹ اپ مکمل ہوا")

setup_camera_for_rtx()
```

### مصنوعی ڈیٹا جنریشن پائپ لائن

مکمل مصنوعی ڈیٹا جنریشن پائپ لائن USD منظرنامہ کمپوزیشن، RTX رینڈرنگ، اور ڈومین رینڈمائزیشن کو جوڑتی ہے تاکہ AI نظام کے لیے تربیتی ڈیٹا تیار کیا جا سکے۔

```python
# مکمل مصنوعی ڈیٹا جنریشن پائپ لائن
import omni.replicator.core as rep
import omni.synthetic_utils.core as synth_core
from PIL import Image
import numpy as np
import os

class SyntheticDataGenerator:
    """
    Isaac Sim کے لیے مکمل مصنوعی ڈیٹا جنریشن پائپ لائن
    """

    def __init__(self, output_dir="./synthetic_data"):
        self.output_dir = output_dir
        os.makedirs(output_dir, exist_ok=True)

        # replicator کا آغاز
        rep.orchestrator.setup_preview()

        # مختلف ڈیٹا کی اقسام کے لیے annotators کو سیٹ اپ کریں
        self.annotators = [
            "rgb",           # رنگین تصاویر
            "distance_to_image_plane",  # گہرائی ڈیٹا
            "instance_segmentation",    # انسٹینس ماسک
            "semantic_segmentation",    # سیمینٹک سیگمینٹیشن
            "bbox_2d_tight",            # 2D باؤنڈنگ باکسز
            "normal"                   # سطح کے نارملز
        ]

        carb.log_info("مصنوعی ڈیٹا جنریٹر کا آغاز ہوا")
        carb.log_info("جسمانی AI کی اہمیت: یہ ظاہر کرتا ہے کہ AI نظام کیسے مصنوعی ڈیٹا جمع کر سکتے ہیں")

    def setup_randomization_graph(self):
        """متغیر کے گراف کو سیٹ اپ کریں"""

        with rep.new_layer():
            # ماحول کو متغیر کریں
            lights = rep.get.light()
            with lights.randomize_position():
                rep.random.uniform((-10, -10, 5), (10, 10, 20))
            with lights.randomize_intensity():
                rep.random.uniform(500, 2000)

            # میٹریلز کو متغیر کریں
            materials = rep.get.material()
            with materials.randomize_roughness():
                rep.random.uniform(0.05, 0.95)
            with materials.randomize_metallic():
                rep.random.uniform(0.0, 1.0)

            # آبجیکٹ کے پوز اور اسکیل کو متغیر کریں
            objects = rep.get.prim_by_type("Mesh")
            with objects.randomize_scale():
                rep.random.uniform((0.5, 0.5, 0.5), (2.0, 2.0, 2.0))
            with objects.randomize_position():
                rep.random.uniform((-5, -5, 0), (5, 5, 0))

    def generate_dataset(self, num_samples=1000):
        """مصنوعی ڈیٹا سیٹ تیار کریں"""

        self.setup_randomization_graph()

        # مختلف ڈیٹا کی اقسام کے لیے writers کو رجسٹر کریں
        writer = rep.WriterRegistry.get("BasicWriter")
        writer.initialize(
            output_dir=self.output_dir,
            rgb=True,
            depth=True,
            semantic_segmentation=True,
            instance_segmentation=True,
            bbox_2d_tight=True,
            orientation="landscape",
            colorize_instance_segmentation=True,
            colorize_semantic_segmentation=True
        )

        # نمونے تیار کریں
        for i in range(num_samples):
            # متغیر کو متحرک کریں
            rep.orchestrator.step()

            # موجودہ فریم لکھیں
            writer.write()

            if i % 100 == 0:
                carb.log_info(f"{i}/{num_samples} مصنوعی نمونے تیار ہوئے")

        # orchestrator کو بند کریں
        rep.orchestrator.stop()

        carb.log_info(f"مصنوعی ڈیٹا سیٹ تیاری مکمل ہوئی. {num_samples} نمونے تیار ہوئے.")
        carb.log_info("ڈیٹا سیٹ محفوظ کیا گیا:", self.output_dir)

# مثال کا استعمال:
# generator = SyntheticDataGenerator("./my_synthetic_dataset")
# generator.generate_dataset(1000)  # 1000 نمونے تیار کریں
```

### ہارڈ ویئر کی ضروریات اور RTX 4070/4080 کے تصورات

Isaac Sim کے ساتھ RTX رینڈرنگ کا استعمال کرتے وقت، ہارڈ ویئر کی صلاحیتیں کارکردگی میں اہم کردار ادا کرتی ہیں۔ روبوٹکس-ہارڈ ویئر-گلسیری کے مطابق، RTX 4070 اور 4080 GPU Isaac Sim کے لیے بہترین صلاحیتیں فراہم کرتے ہیں:

- **RTX 4070**: 12GB VRAM، میڈیم-کمپلیکسٹی مناظر کے لیے مناسب جس میں RTX رینڈرنگ شامل ہو
- **RTX 4080**: 16GB VRAM، پیچیدہ مناظر کو ہینڈل کرنے کے قابل جس میں متعدد لائٹ سورسز اور ہائی ریزولوشن رینڈرنگ شامل ہو

Isaac Sim کے لیے بہترین کارکردگی کے لیے:
- منظر کی پیچیدگی کے لیے کافی VRAM کو یقینی بنائیں

### جسمانی AI کی اہمیت: سیم-ٹو-ریئل ٹرانسفر

یہ مصنوعی ڈیٹا جنریشن فریم ورک ظاہر کرتا ہے کہ AI نظام کیسے محاورہ میں تربیت یافتہ ہو سکتے ہیں جس میں فوٹو ریل اسٹک رینڈرنگ اور ڈومین رینڈمائزیشن کی تکنیکیں استعمال کی جاتی ہیں، پھر حقیقی دنیا کے اطلاقوں میں کامیابی کے ساتھ منتقل کیا جا سکتا ہے۔ یہ سیکھنے کے لیے ڈیٹا کی متنوع، لیبل والی تیاری کو محاورہ میں تیز کرتا ہے جبکہ حقیقی دنیا کے ڈیٹا جمع کرنے کی ضرورت کو کم کرتا ہے۔ ڈومین رینڈمائزیشن کی تکنیکیں یقینی بناتی ہیں کہ محاورہ میں تربیت یافتہ AI ماڈل حقیقی دنیا کے انتظامات میں متغیرات کے لیے مضبوط ہو جاتے ہیں۔
