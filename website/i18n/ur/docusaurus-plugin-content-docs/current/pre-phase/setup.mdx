<ActionBar />

## جائزہ

یہ جامع سیٹ اپ گائیڈ آپ کو Ubuntu 22.04 LTS کو تشکیل دینے میں مدد دے گا جس کے ساتھ ROS 2 ہمبول ہاکسبل، NVIDIA Isaac Sim، اور تمام ضروری وابستگیوں کا مکمل سافٹ ویئر اسٹیک شامل ہے۔

### ضروریات
- NVIDIA Jetson AGX Orin ڈویلپر کٹ (یا مساوی ڈویلپمنٹ اسٹیشن)
- انٹل ریئل سینس D435i ڈیپتھ کیمرہ
- مستحکم انٹرنیٹ کنیکشن
- 100GB+ خالی ڈسک کی جگہ
- ایڈمنسٹریٹر تک رسائی

### تخمینی وقت
- **نیویس**: 4-6 گھنٹے
- **انٹر میڈیٹ**: 2-3 گھنٹے
- **ایکسپرٹ**: 1-2 گھنٹے

## فیز 1: Ubuntu 22.04 LTS انسٹالیشن

### آپشن A: Jetson Orin سیٹ اپ (تجویز کردہ)

1. **JetPack SDK ڈاؤن لوڈ کریں**:
   - ملاحظہ کریں [NVIDIA JetPack ڈاؤن لوڈز](https://developer.nvidia.com/embedded/jetpack)
   - JetPack 5.1.3 یا نئے ورژن کو Orin کے لیے ڈاؤن لوڈ کریں
   - چیک سم تصدیق کریں: `sha256sum JetPack_*_linux_x64_b*.run`

2. **Jetson Orin فلیش کریں**:
   ```bash
   # انسٹالر کو قابل عمل بنائیں
   chmod +x JetPack_*_linux_x64_b*.run

   # انسٹالر چلائیں
   sudo ./JetPack_*_linux_x64_b*.run
   ```

3. **ابتدائی کنفیگریشن**:
   - انٹرنیٹ سے منسلک ہوں (ایتھر نیٹ ترجیح دی جاتی ہے)
   - ایڈمن اہلیت کے ساتھ صارف اکاؤنٹ تخلیق کریں
   - ٹائم زون اور کی بورڈ لے آؤٹ سیٹ کریں
   - سیکورٹی پیچز کے لیے خودکار اپ ڈیٹس فعال کریں

4. **تسطیح انسٹالیشن**:
   ```bash
   # Ubuntu ورژن چیک کریں
   lsb_release -a

   # Jetson کی تفصیلات کی تصدیق کریں
   sudo apt install -y jetson-stats
   jtop
   ```

### آپشن B: x86_64 ڈویلپمنٹ اسٹیشن

1. **Ubuntu 22.04 LTS انسٹال کریں**:
   - ڈاؤن لوڈ ISO از [Ubuntu ریلیز](https://releases.ubuntu.com/22.04/)
   - Rufus (Windows) یا `dd` (Linux/Mac) کا استعمال کرتے ہوئے بوٹ ایبل USB تخلیق کریں
   - USB سے بوٹ کریں اور ڈیفالٹ ترتیبات کے ساتھ انسٹال کریں
   - ڈویلپمنٹ کام کے لیے کم از کم 100GB پارٹیشن یقینی بنائیں

2. **پوسٹ انسٹالیشن اپ ڈیٹس**:
   ```bash
   # سسٹم پیکجز کو اپ ڈیٹ کریں
   sudo apt update && sudo apt upgrade -y

   # ضروری تعمیر کے ٹولز انسٹال کریں
   sudo apt install -y build-essential cmake git curl wget
   ```

### Isaac Sim وابستگیاں انسٹال کریں
```bash
# NVIDIA کنٹینر ٹول کٹ انسٹال کریں
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg \
  && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
    sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
    sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

sudo apt update
sudo apt install -y nvidia-container-toolkit
sudo systemctl restart docker

# Isaac Sim کے لیے مقدمات انسٹال کریں
sudo apt install -y python3-pip python3-dev python3-venv
pip3 install --upgrade pip
```

## فیز 3: ROS 2 ہمبول ہاکسبل انسٹالیشن

### ROS 2 ریپوزٹری شامل کریں
```bash
# مقام سیٹ کریں
sudo locale-gen en_US.UTF-8
export LANG=en_US.UTF-8

# ROS 2 GPG کلید شامل کریں
sudo apt update && sudo apt install -y curl gnupg
curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg

# ذرائع کی فہرست میں ریپوزٹری شامل کریں
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# پیکج انڈیکس کو اپ ڈیٹ کریں
sudo apt update

# ROS 2 ہمبول ڈیسک ٹاپ انسٹال کریں
sudo apt install -y ros-humble-desktop
```

### اضافی ROS 2 پیکجز انسٹال کریں
```bash
# ڈویلپمنٹ ٹولز انسٹال کریں
sudo apt install -y \
  python3-colcon-common-extensions \
  python3-rosdep \
  python3-vcstool \
  build-essential \
  cmake \
  git \
  libbullet-dev \
  python3-bloom \
  python3-catkin-tools \
  python3-pip \
  python3-setuptools \
  wget

# rosdep شروع کریں
sudo rosdep init
rosdep update

# Isaac ROS پیکجز انسٹال کریں
source /opt/ros/humble/setup.bash
sudo apt install -y ros-humble-isaac-ros-* ros-humble-novatel-oem7-driver
```

### ROS 2 ماحول کی ترتیب
```bash
# ~/.bashrc میں شامل کریں
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
echo "source /usr/share/colcon_cd/function/colcon_cd.sh" >> ~/.bashrc
echo "export COLCON_CD_ROOTS_PATHS=$HOME/workspace" >> ~/.bashrc
echo "export ROS_DOMAIN_ID=1" >> ~/.bashrc

# bash کنفیگریشن دوبارہ لوڈ کریں
source ~/.bashrc
```

## فیز 6: ٹیسٹنگ اور تصدیق

### بنیادی ٹیسٹس چلائیں
```bash
# ROS 2 انسٹالیشن ٹیسٹ کریں
source /opt/ros/humble/setup.bash
ros2 topic list

# Isaac Sim ٹیسٹ کریں (الگ ٹرمنل میں)
# Isaac Sim لانچ کریں اور بنیادی کارکردگی کی تصدیق کریں

# ریئل سینس کیمرہ ٹیسٹ کریں
source ~/workspace/physical_ai_env/bin/activate
python3 -c "import pyrealsense2 as rs; print('ریئل سینس SDK لوڈڈ ہو گیا کامیابی سے')"
```

### ٹیسٹ اسکرپٹ تخلیق کریں
```bash
# تصدیق اسکرپٹ تخلیق کریں
cat << 'EOF' > ~/workspace/physical_ai_validation.py
#!/usr/bin/env python3

import sys
import subprocess
import importlib.util

def check_ros():
    """ROS 2 انسٹالیشن چیک کریں"""
    try:
        import rclpy
        print("✓ ROS 2 Python بائنڈنگز: ٹھیک ہے")
        return True
    except ImportError:
        print("✗ ROS 2 Python بائنڈنگز: نہیں ملا")
        return False

def check_realsense():
    """ریئل سینس انسٹالیشن چیک کریں"""
    try:
        import pyrealsense2 as rs
        print("✓ ریئل سینس SDK: ٹھیک ہے")
        return True
    except ImportError:
        print("✗ ریئل سینس SDK: نہیں ملا")
        return False

def check_cuda():
    """CUDA دستیابی چیک کریں"""
    try:
        import torch
        if torch.cuda.is_available():
            print(f"✓ CUDA: ٹھیک ہے (ڈیوائس: {torch.cuda.get_device_name()})")
            return True
        else:
            print("✗ CUDA: دستیاب نہیں")
            return False
    except ImportError:
        print("✗ CUDA: TORCH انسٹال نہیں ہے")
        return False

def main():
    print("فزیکل AI ڈویلپمنٹ ماحول تصدیق")
    print("=" * 50)

    results = []
    results.append(check_ros())
    results.append(check_realsense())
    results.append(check_cuda())

    print("\nتصدیق خلاصہ:")
    print(f"کامیاب: {sum(results)}/{len(results)}")

    if all(results):
        print("🎉 تمام چیکس کامیاب! ماحول فزیکل AI ڈویلپمنٹ کے لیے تیار ہے.")
        return 0
    else:
        print("⚠️  کچھ چیکس ناکام ہوئے. براہ کرم سیٹ اپ گائیڈ کا جائزہ لیں.")
        return 1

if __name__ == "__main__":
    sys.exit(main())
EOF

chmod +x ~/workspace/physical_ai_validation.py
```

### تصدیق چلائیں
```bash
source ~/workspace/physical_ai_env/bin/activate
python3 ~/workspace/physical_ai_validation.py
```

## ٹربل شوٹنگ عام مسائل

### مسئلہ: CUDA نہیں ملا
**حل**:
```bash
# NVIDIA ڈرائیورس کی تصدیق کریں

# CUDA ٹول کٹ دوبارہ انسٹال کریں اگر ضروری ہو

```

**حل**:
```bash

sudo usermod -a -G dialout $USER
sudo cp /etc/udev/rules.d/*realsense* /lib/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger
```

### مسئلہ: ROS 2 کمانڈس نہیں مل رہیں
**حل**:
```bash
# یقینی بنائیں کہ ROS 2 سورسڈ ہے

# اگر ضروری ہو تو bashrc میں مستقل کریں
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
```
