## تعارف: فزیکل AI کا آخری پروجیکٹ

خوش آمدید ہے Physical AI & Humanoid Robotics Bootcamp کے کیپسٹون پروجیکٹ میں! یہ آپ کے تمام سیکھے گئے علم، مہارتوں، اور بصیرتوں کو ایک جامع، خود مختار انسان نما روبوٹکس سسٹم میں ضم کرنے کا موقع ہے۔ یہ پروجیکٹ آپ کو ایک ایسے روبوٹ کو تیار کرنے کی ترغیب دیتا ہے جو کہ قدرتی زبان کے حکم کو سمجھ سکتا ہے، ماحول کا جائزہ لے سکتا ہے، منصوبہ بندی کر سکتا ہے، اور جسمانی دنیا میں کارروائی کر سکتا ہے۔

### پروجیکٹ کا مقصد

اس کیپسٹون پروجیکٹ کا مقصد ایک خود مختار انسان نما روبوٹ تیار کرنا ہے جو مندرجہ ذیل کارکردگی فراہم کرے:

1. **قدرتی زبان کی سمجھ**: 'کچن میں جاؤ اور لال کپ اٹھاؤ' جیسے حکم کو سمجھنا
2. **وژن-لینگویج-ایکشن (VLA) انضمام**: تصویر کو ترجمہ کرنا، کمانڈ کو ایکشن میں تبدیل کرنا
3. **سیمولیشن میں نقل**: Isaac Sim میں 13 ہفتوں کے سیکھنے کو اکٹھا کرنا
4. **خود مختار عمل**: انسان کی مداخلت کے بغیر کام کرنا
5. **.UR. ترجمہ**: اردو زبان کے صارفین کی مکمل حمایت

## پروجیکٹ کا ڈھانچہ

### مرحلہ 1: سسٹم ڈیزائن اور آرکیٹیکچر

#### کلائنٹ سائیڈ (ویب انٹرفیس)
- **ویب ایپلی کیشن**: صارف کمانڈز کو جمع کرنے کے لیے
- **وائس ان پٹ**: OpenAI Whisper کا استعمال کرتے ہوئے تقریر کی تبدیلی
- **ویب سوکیٹس**: ریئل ٹائم کمنیکیشن کے لیے

#### سرور سائیڈ (ROS 2 نوڈس)
- **LLM انٹیگریشن نوڈ**: GPT-4 کا استعمال کرتے ہوئے کمانڈ کی تشریح
- **وژن نوڈ**: Isaac Sim سے اشیاء کی پہچان
- **پلاننگ نوڈ**: حرکت اور مینیپولیشن کا منصوبہ
- **ایکشن نوڈ**: Isaac Sim کے ساتھ تعامل

#### سیمولیشن ماحول (Isaac Sim)
- **انسان نما روبوٹ**: 13 ہفتوں میں تیار کردہ ماڈل
- **فیکٹری ماحول**: کچن، لاؤنگ روم، کمرہ
- **اشیاء**: کپ، بال، باکس، وغیرہ

// src/components/VoiceCommandInterface.jsx
import React, { useState, useRef } from 'react';
import { io } from 'socket.io-client';

const VoiceCommandInterface = () => {
  const [isListening, setIsListening] = useState(false);
  const [transcript, setTranscript] = useState('');
  const [response, setResponse] = useState('');
  const [connectionStatus, setConnectionStatus] = useState('disconnected');

  const socketRef = useRef(null);
  const recognitionRef = useRef(null);

  // Socket.IO connection
  useEffect(() => {
    socketRef.current = io(process.env.REACT_APP_SERVER_URL);

    socketRef.current.on('connect', () => {
      setConnectionStatus('connected');
    });

    socketRef.current.on('disconnect', () => {
      setConnectionStatus('disconnected');
    });

    socketRef.current.on('robot_response', (data) => {
      setResponse(data.message);
    });

    return () => {
      socketRef.current.disconnect();
    };
  }, []);

  // Voice recognition setup
  useEffect(() => {
    if ('webkitSpeechRecognition' in window) {
      recognitionRef.current = new window.webkitSpeechRecognition();
      recognitionRef.current.continuous = false;
      recognitionRef.current.interimResults = false;
      recognitionRef.current.lang = 'en-US';

      recognitionRef.current.onresult = (event) => {
        const transcript = event.results[0][0].transcript;
        setTranscript(transcript);
        sendCommand(transcript);
      };

      recognitionRef.current.onerror = (event) => {
        console.error('Speech recognition error', event.error);
        setIsListening(false);
      };
    }
  }, []);

  const startListening = () => {
    if (recognitionRef.current) {
      recognitionRef.current.start();
      setIsListening(true);
    }
  };

  const stopListening = () => {
    if (recognitionRef.current) {
      recognitionRef.current.stop();
      setIsListening(false);
    }
  };

  const sendCommand = (command) => {
    if (socketRef.current) {
      socketRef.current.emit('voice_command', { command });
    }
  };

  const handleManualSubmit = () => {
    if (transcript.trim()) {
      sendCommand(transcript);
    }
  };

  return (
    <div className="voice-command-interface">
      <div className="status-bar">
        <div className={`connection-status ${connectionStatus}`}>
          Status: {connectionStatus}
        </div>
      </div>

      <div className="command-input">
        <textarea
          value={transcript}
          onChange={(e) => setTranscript(e.target.value)}
          placeholder="Enter your command or use voice input..."
          rows={4}
        />

        <div className="controls">
          <button
            onClick={isListening ? stopListening : startListening}
            className={`voice-button ${isListening ? 'listening' : ''}`}
          >
            {isListening ? '⏹️ Stop' : '🎤 Listen'}
          </button>

          <button onClick={handleManualSubmit} disabled={!transcript.trim()}>
            Submit Command
          </button>
        </div>
      </div>

      <div className="response-area">
        <h3>Robot Response:</h3>
        <div className="response-content">
          {response || 'Waiting for robot response...'}
        </div>
      </div>
    </div>
  );
};

export default VoiceCommandInterface;

```python
#!/usr/bin/env python3
# src/physical_ai_capstone/robot_command_processor.py

import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Pose
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import openai
import json
import asyncio
from typing import Dict, List, Optional
import numpy as np

class RobotCommandProcessor(Node):
    """
    کمانڈز کو سنبھالنے اور VLA پائپ لائن کے ذریعے انجام دینے کے لیے ROS 2 نوڈ
    """
    def __init__(self):
        super().__init__('robot_command_processor')

        # OpenAI API کلید کی ترتیب
        openai.api_key = self.declare_parameter('openai_api_key', '').value

        # سبسکرائبرز اور پبلشرز
        self.command_sub = self.create_subscription(
            String,
            'voice_commands',
            self.command_callback,
            10
        )

        self.image_sub = self.create_subscription(
            Image,
            '/camera/rgb/image_raw',
            self.image_callback,
            10
        )

        self.action_pub = self.create_publisher(
            String,
            'robot_actions',
            10
        )

        # دیگر متغیرات
        self.cv_bridge = CvBridge()
        self.current_image = None
        self.is_processing = False

        # ٹائمرز
        self.process_timer = self.create_timer(0.1, self.process_commands)

        self.get_logger().info('Robot Command Processor initialized')

    def image_callback(self, msg: Image):
        """
        کیمرہ امیج کو اپ ڈیٹ کریں
        """
        self.current_image = msg

    def command_callback(self, msg: String):
        """
        وائس کمانڈز کو عمل کریں
        """
        if not self.is_processing:
            self.get_logger().info(f'Received command: {msg.data}')
            self.process_command_async(msg.data)

    def process_command_async(self, command: str):
        """
        کمانڈ کو بے ترتیب طور پر عمل کریں
        """
        def run_async():
            loop = asyncio.new_event_loop()
            asyncio.set_event_loop(loop)
            loop.run_until_complete(self.process_command_vla(command))

        import threading
        thread = threading.Thread(target=run_async)
        thread.start()

    async def process_command_vla(self, command: str):
        """
        VLA (وژن-زبان-ایکشن) پائپ لائن کا استعمال کرتے ہوئے کمانڈ کو عمل کریں
        """
        self.is_processing = True
        try:
            self.get_logger().info(f'Processing command through VLA: {command}')

            # 1. وژن: ماحول کا جائزہ لیں
            environment_state = await self.get_environment_state()

            # 2. زبان: کمانڈ کی تشریح کریں
            action_plan = await self.interpret_command(command, environment_state)

            # 3. ایکشن: منصوبے کو انجام دیں
            success = await self.execute_action_plan(action_plan)

            if success:
                response_msg = String()
                response_msg.data = f"Command '{command}' executed successfully"
                self.action_pub.publish(response_msg)
            else:
                response_msg = String()
                response_msg.data = f"Failed to execute command: {command}"
                self.action_pub.publish(response_msg)

        except Exception as e:
            self.get_logger().error(f'Error processing command: {str(e)}')
            error_msg = String()
            error_msg.data = f"Error processing command: {str(e)}"
            self.action_pub.publish(error_msg)
        finally:
            self.is_processing = False

    async def get_environment_state(self) -> Dict:
        """
        Isaac Sim سے ماحول کی حالت حاصل کریں
        """
        # اس مثال کے لیے، ہم ایک جھوٹا ماحول کی حالت لوٹاتے ہیں
        # حقیقی نفاذ میں، یہ Isaac Sim سے اصل ڈیٹا حاصل کرے گا
        environment_state = {
            "objects": {
                "red_cup": {
                    "position": [1.2, 0.5, 0.1],
                    "orientation": [0, 0, 0, 1],
                    "properties": {"color": "red", "shape": "cylinder", "size": "medium"}
                },
                "blue_ball": {
                    "position": [0.8, -0.3, 0.2],
                    "orientation": [0, 0, 0, 1],
                    "properties": {"color": "blue", "shape": "sphere", "size": "small"}
                },
                "kitchen_table": {
                    "position": [2.0, 1.0, 0.0],
                    "orientation": [0, 0, 0, 1],
                    "properties": {"type": "furniture", "size": "large"}
                }
            },
            "locations": {
                "kitchen": {"coordinates": [2.0, 1.0, 0.0]},
                "living_room": {"coordinates": [0.0, 0.0, 0.0]},
                "bedroom": {"coordinates": [-1.0, 1.5, 0.0]}
            },
            "robot_pose": {"position": [0.0, 0.0, 0.0], "orientation": [0, 0, 0, 1]},
            "navigation_map": {
                "obstacles": [],
                "free_space": [[x, y] for x in range(-5, 6) for y in range(-5, 6)]
            }
        }

        return environment_state

    async def interpret_command(self, command: str, environment_state: Dict) -> List[Dict]:
        """
        LLM کا استعمال کرتے ہوئے کمانڈ کی تشریح کریں اور ایکشن منصوبہ بنائیں
        """
        # OpenAI GPT-4 کا استعمال کرتے ہوئے کمانڈ کی تشریح
        system_prompt = f"""
        آپ ایک انسان نما روبوٹ کے لیے کمانڈ تشریح کنندہ ہیں۔ آپ کا کام قدرتی زبان کے حکم کو مخصوص، قابلِ عمل ایکشن میں تبدیل کرنا ہے۔

        موجودہ ماحول کی حالت:
        {json.dumps(environment_state, indent=2)}

        آؤٹ پٹ کی شکل: JSON جس میں "actions" ارے ہو جس میں یہ شامل ہوں:
        - action_type: ایکشن کی قسم (navigate_to، grasp_object، place_object، speak، وغیرہ)
        - parameters: ایکشن کے لیے مخصوص پیرامیٹر
        - priority: عمل کی ترجیح (1-10)

        مثال:
        ان پٹ: "کچن میں جائیں اور لال کپ اٹھائیں"
        آؤٹ پٹ: {{
            "actions": [
                {{
                    "action_type": "navigate_to",
                    "parameters": {{"location": "kitchen"}},
                    "priority": 5
                }},
                {{
                    "action_type": "locate_object",
                    "parameters": {{"object_name": "red cup", "search_area": [2.0, 1.0, 0.0]}},
                    "priority": 6
                }},
                {{
                    "action_type": "grasp_object",
                    "parameters": {{"object_name": "red cup", "position": [1.2, 0.5, 0.1]}},
                    "priority": 7
                }}
            ]
        }}
        """

        try:
            response = await openai.ChatCompletion.acreate(
                model="gpt-4o",
                messages=[
                    {"role": "system", "content": system_prompt},
                    {"role": "user", "content": f"Command: {command}"}
                ],
                temperature=0.1,
                max_tokens=500
            )

            response_text = response.choices[0].message.content.strip()

            # JSON جواب نکالیں
            if response_text.startswith("```json"):
                response_text = response_text[7:]
            if response_text.endswith("```"):
                response_text = response_text[:-3]

            parsed_response = json.loads(response_text)
            action_plan = parsed_response.get("actions", [])

            self.get_logger().info(f'Generated action plan: {action_plan}')
            return action_plan

        except Exception as e:
            self.get_logger().error(f'Error interpreting command: {str(e)}')
            # ڈیفالٹ ایکشن منصوبہ لوٹائیں
            return [
                {
                    "action_type": "speak",
                    "parameters": {"message": f"Sorry, I couldn't understand the command: {command}"},
                    "priority": 1
                }
            ]

    async def execute_action_plan(self, action_plan: List[Dict]) -> bool:
        """
        ایکشن منصوبے کو انجام دیں
        """
        for action in action_plan:
            success = await self.execute_single_action(action)
            if not success:
                self.get_logger().error(f'Action failed: {action}')
                return False

        return True

    async def execute_single_action(self, action: Dict) -> bool:
        """
        ایک ایکشن انجام دیں
        """
        action_type = action.get("action_type")
        parameters = action.get("parameters", {})

        self.get_logger().info(f'Executing action: {action_type} with params: {parameters}')

        if action_type == "navigate_to":
            return await self.execute_navigation(parameters)
        elif action_type == "grasp_object":
            return await self.execute_grasp(parameters)
        elif action_type == "place_object":
            return await self.execute_place(parameters)
        elif action_type == "speak":
            return await self.execute_speak(parameters)
        elif action_type == "locate_object":
            return await self.execute_locate(parameters)
        else:
            self.get_logger().warn(f'Unknown action type: {action_type}')
            return False

    async def execute_navigation(self, params: Dict) -> bool:
        """
        نیویگیشن ایکشن انجام دیں
        """
        target_location = params.get("location")
        if target_location:
            # Isaac Sim نیویگیشن سروس کال کریں
            self.get_logger().info(f'Navigating to {target_location}')
            # یہاں Isaac Sim نیویگیشن کا کوڈ ہوگا
            return True
        return False

    async def execute_grasp(self, params: Dict) -> bool:
        """
        گریس ایکشن انجام دیں
        """
        object_name = params.get("object_name")
        position = params.get("position", [0, 0, 0])

        if object_name:
            self.get_logger().info(f'Grasping {object_name} at {position}')
            # یہاں Isaac Sim گریس کا کوڈ ہوگا
            return True
        return False

    async def execute_place(self, params: Dict) -> bool:
        """
        جگہ ایکشن انجام دیں
        """
        position = params.get("position", [0, 0, 0])
        self.get_logger().info(f'Placing object at {position}')
        # یہاں Isaac Sim جگہ کا کوڈ ہوگا
        return True

    async def execute_speak(self, params: Dict) -> bool:
        """
        بولنا ایکشن انجام دیں
        """
        message = params.get("message", "")
        self.get_logger().info(f'Speaking: {message}')
        # یہاں TTS کا کوڈ ہوگا
        return True

    async def execute_locate(self, params: Dict) -> bool:
        """
        مقام ایکشن انجام دیں
        """
        object_name = params.get("object_name")
        search_area = params.get("search_area", [0, 0, 0])

        self.get_logger().info(f'Locating {object_name} in area {search_area}')
        # یہاں Isaac Sim اشیاء کی تلاش کا کوڈ ہوگا
        return True

def main(args=None):
    rclpy.init(args=args)

    node = RobotCommandProcessor()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        node.get_logger().info('Shutting down Robot Command Processor')
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

```python
# src/physical_ai_capstone/isaac_sim_bridge.py

import carb
import omni
from omni.isaac.core import World
from omni.isaac.core.utils.stage import add_reference_to_stage
from omni.isaac.core.utils.prims import get_prim_at_path
from omni.isaac.core.robots import Robot

from omni.isaac.core.utils.viewports import set_camera_view
from omni.isaac.core.materials import OmniPBR
from pxr import Gf
import numpy as np
import asyncio
import threading
from typing import Dict, List, Optional

class IsaacSimBridge:
    """
    Isaac Sim اور ROS 2 کے درمیان پل
    """
    def __init__(self):
        self.world = None
        self.robot = None
        self.scene_objects = {}
        self.navigation_map = None

        # Isaac Sim دنیا کو شروع کریں
        self.initialize_world()

    def initialize_world(self):
        """
        Isaac Sim دنیا کو شروع کریں
        """
        self.world = World(stage_units_in_meters=1.0)

        # ایک سادہ ماحول لوڈ کریں
        assets_root_path = get_assets_root_path()
        if assets_root_path is None:
            carb.log_error("Could not find Isaac Sim assets path")
            return False

        # ہیومنوائڈ روبوٹ لوڈ کریں
        robot_asset_path = f"{assets_root_path}/Isaac/Robots/Humanoid/humanoid.usd"
        add_reference_to_stage(usd_path=robot_asset_path, prim_path="/World/Humanoid")

        # ایک سادہ ماحول کا منظر تیار کریں
        self.setup_environment()

        return True

    def setup_environment(self):
        """
        سیمولیشن ماحول سیٹ اپ کریں
        """
        # کچن، لاؤنگ روم، کمرہ کے لیے سادہ جیومیٹر تیار کریں
        # کچن میز
        self.world.scene.add(
            FixedCuboid(
                prim_path="/World/KitchenTable",
                name="kitchen_table",
                position=np.array([2.0, 1.0, 0.0]),
                size=np.array([1.0, 0.8, 0.8]),
                color=np.array([0.8, 0.6, 0.4])
            )
        )

        # لال کپ
        self.world.scene.add(
            VisualCuboid(
                prim_path="/World/RedCup",
                name="red_cup",
                position=np.array([2.1, 1.1, 0.8]),
                size=np.array([0.05, 0.05, 0.1]),
                color=np.array([0.9, 0.1, 0.1])
            )
        )

        # نیویگیشن میپ تیار کریں
        self.navigation_map = self.create_navigation_map()

    def create_navigation_map(self) -> Dict:
        """
        سیمولیشن ماحول کے لیے نیویگیشن میپ تیار کریں
        """
        # 10x10 میٹر گرڈ تیار کریں
        grid_size = 20  # 20x20 گرڈ
        cell_size = 0.5  # ہر سیل 0.5x0.5 میٹر

        navigation_map = {
            "grid_size": grid_size,
            "cell_size": cell_size,
            "obstacles": [],
            "free_space": []
        }

        # سب فری اسپیس کے طور پر شروع کریں
        for x in range(grid_size):
            for y in range(grid_size):
                world_x = (x - grid_size/2) * cell_size
                world_y = (y - grid_size/2) * cell_size
                navigation_map["free_space"].append([world_x, world_y])

        # بعد میں رکاوٹوں کو شامل کیا جا سکتا ہے
        return navigation_map

    async def execute_navigation(self, target_position: List[float]) -> bool:
        """
        Isaac Sim میں نیویگیشن انجام دیں
        """
        try:
            # روبوٹ کو ہدف کی طرف منتقل کریں
            if self.robot:
                # اس نفاذ میں، ہم سادہ ٹیلیپورٹیشن کا استعمال کریں گے
                # حقیقی نفاذ میں، A* یا RRT کا استعمال کریں گے
                self.robot.set_world_pose(position=np.array(target_position))
                return True
            return False
        except Exception as e:
            carb.log_error(f"Navigation error: {str(e)}")
            return False

    async def execute_grasp(self, object_name: str, position: List[float]) -> bool:
        """
        Isaac Sim میں گریس انجام دیں
        """
        try:
            # اشیاء کو تلاش کریں اور گریس کریں
            object_prim = get_prim_at_path(f"/World/{object_name.replace(' ', '_')}")
            if object_prim:
                # گریس لاجک یہاں ہوگا
                carb.log_info(f"Grasping {object_name} at {position}")
                return True
            return False
        except Exception as e:
            carb.log_error(f"Grasp error: {str(e)}")
            return False

    async def get_environment_state(self) -> Dict:
        """
        Isaac Sim سے ماحول کی حالت حاصل کریں
        """
        # سیمولیشن سے اشیاء کے مقامات حاصل کریں
        environment_state = {
            "objects": {},
            "robot_pose": {"position": [0, 0, 0], "orientation": [0, 0, 0, 1]},
            "navigation_map": self.navigation_map
        }

        # اشیاء کی فہرست حاصل کریں
        for prim in self.world.scene.objects:
            if hasattr(prim, 'get_world_pose'):
                pos, orn = prim.get_world_pose()
                environment_state["objects"][prim.name] = {
                    "position": pos.tolist(),
                    "orientation": orn.tolist()
                }

        # روبوٹ کی پوزیشن حاصل کریں
        if self.robot:
            pos, orn = self.robot.get_world_pose()
            environment_state["robot_pose"]["position"] = pos.tolist()
            environment_state["robot_pose"]["orientation"] = orn.tolist()

        return environment_state

    def run_simulation(self):
        """
        سیمولیشن چلائیں
        """
        # دنیا کو 1000 سٹیپس تک چلائیں
        for i in range(1000):
            self.world.step(render=True)

            if i % 100 == 0:
                carb.log_info(f"Simulation step {i}")

        return True

class IsaacSimROS2Bridge(Node):
    """
    Isaac Sim اور ROS 2 کے درمیان ROS 2 نوڈ کے طور پر پل
    """
    def __init__(self):
        super().__init__('isaac_sim_bridge')

        # Isaac Sim برج شروع کریں
        self.isaac_bridge = IsaacSimBridge()

        # سبسکرائبرز اور پبلشرز
        self.action_sub = self.create_subscription(
            String,
            'robot_actions',
            self.action_callback,
            10
        )

        self.sim_state_pub = self.create_publisher(
            String,
            'simulation_state',
            10
        )

        # سیمولیشن ٹائمر
        self.sim_timer = self.create_timer(0.016, self.simulation_step)  # ~60 FPS

        self.get_logger().info('Isaac Sim Bridge initialized')

    def action_callback(self, msg: String):
        """
        ROS 2 ایکشن کو Isaac Sim میں انجام دیں
        """
        try:
            action_data = json.loads(msg.data)

            if action_data["action_type"] == "navigate_to":
                asyncio.run(
                    self.isaac_bridge.execute_navigation(
                        action_data["parameters"]["position"]
                    )
                )
            elif action_data["action_type"] == "grasp_object":
                asyncio.run(
                    self.isaac_bridge.execute_grasp(
                        action_data["parameters"]["object_name"],
                        action_data["parameters"]["position"]
                    )
                )

        except Exception as e:
            self.get_logger().error(f'Error executing action: {str(e)}')

    def simulation_step(self):
        """
        Isaac Sim میں ایک سٹیپ چلائیں
        """
        if self.isaac_bridge.world:
            self.isaac_bridge.world.step(render=True)

            # ماحول کی حالت شائع کریں
            env_state = asyncio.run(self.isaac_bridge.get_environment_state())
            state_msg = String()
            state_msg.data = json.dumps(env_state)
            self.sim_state_pub.publish(state_msg)

    except KeyboardInterrupt:
        pass
    finally:
        rclpy.shutdown()

import cv2
import numpy as np
import torch
from transformers import DetrImageProcessor, DetrForObjectDetection
from PIL import Image
import requests
from typing import Dict, List, Tuple

class VisionComponent:
    """
    VLA سسٹم کے لیے وژن کمپوننٹ
    """
    def __init__(self):
        # DETR ماڈل لوڈ کریں (Object detection)
        self.processor = DetrImageProcessor.from_pretrained("facebook/detr-resnet-50")
        self.model = DetrForObjectDetection.from_pretrained("facebook/detr-resnet-50")

        # ڈیوائس کا تعین کریں (GPU اگر دستیاب ہو)
        self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        self.model.to(self.device)

        # کلاسز کی فہرست (COCO ڈیٹا سیٹ کے لیے)
        self.coco_classes = [
            'person', 'bicycle', 'car', 'motorcycle', 'airplane', 'bus', 'train', 'truck',
            'boat', 'traffic light', 'fire hydrant', 'stop sign', 'parking meter', 'bench',
            'bird', 'cat', 'dog', 'horse', 'sheep', 'cow', 'elephant', 'bear', 'zebra',
            'giraffe', 'backpack', 'umbrella', 'handbag', 'tie', 'suitcase', 'frisbee',
            'skis', 'snowboard', 'sports ball', 'kite', 'baseball bat', 'baseball glove',
            'skateboard', 'surfboard', 'tennis racket', 'bottle', 'wine glass', 'cup',
            'fork', 'knife', 'spoon', 'bowl', 'banana', 'apple', 'sandwich', 'orange',
            'broccoli', 'carrot', 'hot dog', 'pizza', 'donut', 'cake', 'chair', 'couch',
            'potted plant', 'bed', 'dining table', 'toilet', 'tv', 'laptop', 'mouse',
            'remote', 'keyboard', 'cell phone', 'microwave', 'oven', 'toaster', 'sink',
            'refrigerator', 'book', 'clock', 'vase', 'scissors', 'teddy bear', 'hair drier', 'toothbrush'
        ]

    def detect_objects(self, image_path_or_array) -> List[Dict]:
        """
        تصویر میں اشیاء کا پتہ لگائیں
        :param image_path_or_array: تصویر کا پاتھ یا numpy ارے
        :return: اشیاء کی فہرست کے ساتھ ڈکشنری
        """
        # تصویر لوڈ کریں
        if isinstance(image_path_or_array, str):
            image = Image.open(image_path_or_array)
        else:
            # numpy ارے کو PIL امیج میں تبدیل کریں
            image = Image.fromarray(image_path_or_array.astype('uint8'), 'RGB')

        # تصویر کو پراسیس کریں
        inputs = self.processor(images=image, return_tensors="pt")
        inputs = {k: v.to(self.device) for k, v in inputs.items()}

        # ماڈل کے ذریعے فارورڈ پاس
        with torch.no_grad():
            outputs = self.model(**inputs)

        # نتائج کو پوسٹ پروسیس کریں
        target_sizes = torch.tensor([image.size[::-1]])
        results = self.processor.post_process_object_detection(
            outputs, target_sizes=target_sizes, threshold=0.9
        )[0]

        # نتائج کو فارمیٹ کریں
        detected_objects = []
        for score, label, box in zip(results["scores"], results["labels"], results["boxes"]):
            detected_objects.append({
                "name": self.coco_classes[label],
                "confidence": score.item(),
                "bbox": box.tolist(),  # [x_min, y_min, x_max, y_max]
                "center": [(box[0] + box[2]) / 2, (box[1] + box[3]) / 2]  # سینٹر کوآرڈینیٹ
            })

        return detected_objects

    def get_environment_state_from_image(self, image_path_or_array) -> Dict:
        """
        تصویر سے ماحول کی حالت حاصل کریں
        :param image_path_or_array: تصویر کا پاتھ یا numpy ارے
        :return: ماحول کی حالت کے ساتھ ڈکشنری
        """
        detected_objects = self.detect_objects(image_path_or_array)

        environment_state = {
            "objects": {},
            "image_analysis": {
                "object_count": len(detected_objects),
                "dominant_colors": self.extract_dominant_colors(image_path_or_array),
                "scene_classification": self.classify_scene(image_path_or_array)
            }
        }

        # اشیاء کو فارمیٹ کریں
        for obj in detected_objects:
            obj_name = obj["name"]
            if obj_name not in environment_state["objects"]:
                environment_state["objects"][obj_name] = []

            environment_state["objects"][obj_name].append({
                "confidence": obj["confidence"],
                "bbox": obj["bbox"],
                "center": obj["center"]
            })

        return environment_state

    def extract_dominant_colors(self, image_path_or_array) -> List[Tuple[int, int, int]]:
        """
        تصویر سے غالب رنگ نکالیں
        :param image_path_or_array: تصویر کا پاتھ یا numpy ارے
        :return: غالب رنگوں کی فہرست
        """
        if isinstance(image_path_or_array, str):
            image = cv2.imread(image_path_or_array)
        else:
            image = image_path_or_array

        # تصویر کو RGB میں تبدیل کریں
        image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

        # تصویر کو ریسائز کریں (کارکردگی کے لیے)
        image_resized = cv2.resize(image_rgb, (50, 50))

        # تصویر کو 2D میں تبدیل کریں
        pixels = image_resized.reshape(-1, 3)

        # K-means کلاسٹرنگ کا استعمال کرتے ہوئے غالب رنگ حاصل کریں
        from sklearn.cluster import KMeans
        kmeans = KMeans(n_clusters=5, random_state=42)
        kmeans.fit(pixels)

        dominant_colors = kmeans.cluster_centers_.astype(int)
        return [tuple(color) for color in dominant_colors]

    def classify_scene(self, image_path_or_array) -> str:
        """
        تصویر کے منظر کی تصنیف کریں
        :param image_path_or_array: تصویر کا پاتھ یا numpy ارے
        :return: منظر کی تصنیف
        """
        # یہ ایک جھوٹا نفاذ ہے
        # حقیقی نفاذ میں، ایک تربیت یافتہ منظر تصنیف ماڈل استعمال کیا جائے گا
        detected_objects = self.detect_objects(image_path_or_array)

        # اشیاء کی بنیاد پر منظر کی تصنیف کریں
        object_names = [obj["name"] for obj in detected_objects]

        if "dining table" in object_names or "chair" in object_names:
            return "dining_area"
        elif "couch" in object_names or "tv" in object_names:
            return "living_room"
        elif "bed" in object_names:
            return "bedroom"
        elif "kitchen" in object_names or "refrigerator" in object_names:
            return "kitchen"
        else:
            return "unknown"

# src/physical_ai_capstone/llm_component.py

import openai
import json
from typing import Dict, List
import asyncio
import logging

class LLMComponent:
    """
    VLA سسٹم کے لیے LLM کمپوننٹ
    """
    def __init__(self, api_key: str, model: str = "gpt-4o"):
        """
        :param api_key: OpenAI API کلید
        :param model: استعمال کرنے کے لیے GPT ماڈل
        """
        openai.api_key = api_key
        self.model = model
        self.conversation_history = []

        # لاگنگ کا تعین کریں
        logging.basicConfig(level=logging.INFO)
        self.logger = logging.getLogger(__name__)

    async def interpret_command(self, command: str, environment_state: Dict) -> List[Dict]:
        """
        قدرتی زبان کے حکم کی تشریح کریں اور ایکشن منصوبہ بنائیں
        :param command: قدرتی زبان کا حکم
        :param environment_state: ماحول کی موجودہ حالت
        :return: ایکشن منصوبے کی فہرست
        """
        # VLA کے لیے سسٹم پرومپٹ تیار کریں
        system_prompt = f"""
        آپ ایک وژن-زبان-ایکشن (VLA) ماڈل ہیں جو انسان نما روبوٹ کے لیے کمانڈز کی تشریح کرتا ہے۔ آپ کا کام یہ ہے کہ قدرتی زبان کے حکم کو سمجھیں، موجودہ ماحول کی حالت کا جائزہ لیں، اور اسے قابلِ عمل ایکشن میں تبدیل کریں۔

        موجودہ ماحول کی حالت:
        {json.dumps(environment_state, indent=2, ensure_ascii=False)}

        ضروریات:
        1. ماحول کی حالت کو دیکھیں اور کمانڈ کے ساتھ مطابقت دیکھیں
        2. اگر کمانڈ میں کوئی چیز کا حوالہ دیا گیا ہو تو، چیک کریں کہ کیا وہ ماحول میں موجود ہے
        3. اگر چیز ماحول میں نہ ہو تو، اس کی تلاش کا منصوبہ بنائیں
        4. ایکشن منصوبہ میں ترجیح کی بنیاد پر ترتیب دیں (1-10، 10 سب سے زیادہ ترجیح یافتہ)

        ایکشن اقسام:
        - navigate_to: کسی جگہ پر جانے کے لیے (parameters: destination coordinates)
        - locate_object: چیز تلاش کرنے کے لیے (parameters: object_name, search_area)
        - grasp_object: چیز تھامنے کے لیے (parameters: object_name, position)
        - place_object: چیز رکھنے کے لیے (parameters: position)
        - speak: کچھ کہنے کے لیے (parameters: message)
        - follow: کسی کے پیچھے چلنے کے لیے (parameters: target)

        جواب کی شکل:
        {{
            "actions": [
                {{
                    "action_type": "navigate_to",
                    "parameters": {{"destination": [x, y, z]}},
                    "priority": 5
                }}
            ]
        }}
        """

        try:
            response = await openai.ChatCompletion.acreate(
                model=self.model,
                messages=[
                    {"role": "system", "content": system_prompt},
                    {"role": "user", "content": f"Command: {command}"}
                ],
                temperature=0.1,
                max_tokens=800
            )

            response_text = response.choices[0].message.content.strip()

            # JSON جواب نکالیں
            if response_text.startswith("```json"):
                response_text = response_text[7:]  # ```json ہٹائیں
            if response_text.endswith("```"):
                response_text = response_text[:-3]  # ``` ہٹائیں

            parsed_response = json.loads(response_text)
            action_plan = parsed_response.get("actions", [])

            # گفتگو کی تاریخ میں شامل کریں
            self.conversation_history.append({
                "command": command,
                "environment_state": environment_state,
                "action_plan": action_plan
            })

            self.logger.info(f"Generated action plan for command: {command}")
            return action_plan

        except json.JSONDecodeError as e:
            self.logger.error(f"Error parsing LLM response: {e}")
            self.logger.error(f"Response text: {response_text}")
            return self._get_default_action_plan(command)
        except Exception as e:
            self.logger.error(f"Error interpreting command: {str(e)}")
            return self._get_default_action_plan(command)

    def _get_default_action_plan(self, command: str) -> List[Dict]:
        """
        ڈیفالٹ ایکشن منصوبہ لوٹائیں اگر LLM ناکام ہو جائے
        :param command: اصل کمانڈ
        :return: ڈیفالٹ ایکشن منصوبہ
        """
        return [
            {
                "action_type": "speak",
                "parameters": {"message": f"Sorry, I couldn't understand the command: {command}"},
                "priority": 1
            }
        ]

    async def generate_response(self, command: str, action_plan: List[Dict]) -> str:

        :param command: اصل کمانڈ

        :return: صارف کے جواب کے لیے پیغام
        """
        response_prompt = f"""
        آپ ایک دوستانہ انسان نما روبوٹ ہیں۔ آپ کو ایک کمانڈ ملا ہے اور اس کے لیے ایکشن منصوبہ تیار کیا گیا ہے۔ اب آپ کو اس بات کا اظہار کرنا ہے کہ آپ کمانڈ کو سمجھ گئے ہیں اور اس پر عمل کریں گے۔

        کمانڈ: {command}

        ایکشن منصوبہ:
        {json.dumps(action_plan, indent=2, ensure_ascii=False)}

        جواب کی ضروریات:
        1. دوستانہ اور مثبت لہجہ
        2. کمانڈ کی تصدیق (کہ آپ نے سمجھ لیا ہے)
        3. اس کا اظہار کریں کہ آپ اس پر عمل کریں گے

from typing import Dict, List
import math

class ActionComponent(Node):
    """
    VLA سسٹم کے لیے ایکشن کمپوننٹ
    """
    def __init__(self):
        super().__init__('action_component')

        # ROS 2 پبلشرز
        self.joint_trajectory_pub = self.create_publisher(
            JointTrajectory, '/joint_trajectory_controller/joint_trajectory', 10
        )
        self.navigation_goal_pub = self.create_publisher(
            Pose, '/goal_pose', 10
        )
        self.tts_pub = self.create_publisher(
            String, '/tts_input', 10
        )

        # ROS 2 سبسکرائبرز
        self.joint_state_sub = self.create_subscription(
            JointState, '/joint_states', self.joint_state_callback, 10
        )
        self.odometry_sub = self.create_subscription(
            # Odometry یا PoseStamped
            String, '/odom', self.odometry_callback, 10  # جگہ دار
        )

        # اندرونی حالت
        self.current_joint_states = None
        self.current_pose = None
        self.is_executing = False

        self.get_logger().info('Action Component initialized')

    def joint_state_callback(self, msg: JointState):
        """
        جوائنٹ سٹیٹس کو اپ ڈیٹ کریں
        """
        self.current_joint_states = msg

    def odometry_callback(self, msg):
        """
        روبوٹ کی پوزیشن کو اپ ڈیٹ کریں
        """
        # اس کو اصل Odometry یا PoseStamped میسج کے لیے اپ ڈیٹ کیا جائے گا
        pass

    async def execute_action_plan(self, action_plan: List[Dict]) -> bool:
        """
        ایکشن منصوبے کو انجام دیں
        :param action_plan: ایکشن منصوبے کی فہرست
        :return: کامیابی کا نتیجہ
        """
        if self.is_executing:
            self.get_logger().warn('Action component already executing')
            return False

        self.is_executing = True

        try:
            for action in action_plan:
                success = await self.execute_single_action(action)
                if not success:
                    self.get_logger().error(f'Action failed: {action}')
                    return False

                # چھوٹا وقفہ ہر ایکشن کے بعد
                await asyncio.sleep(0.1)

            return True
        finally:
            self.is_executing = False

    async def execute_single_action(self, action: Dict) -> bool:
        """
        ایک ایکشن انجام دیں
        :param action: ایکشن ڈکشنری
        :return: کامیابی کا نتیجہ
        """
        action_type = action.get("action_type")
        parameters = action.get("parameters", {})

        self.get_logger().info(f'Executing action: {action_type} with params: {parameters}')

        if action_type == "navigate_to":
            return await self.execute_navigate_to(parameters)
        elif action_type == "grasp_object":
            return await self.execute_grasp_object(parameters)
        elif action_type == "place_object":
            return await self.execute_place_object(parameters)
        elif action_type == "speak":
            return await self.execute_speak(parameters)
        elif action_type == "follow":
            return await self.execute_follow(parameters)
        elif action_type == "locate_object":
            return await self.execute_locate_object(parameters)
        else:
            self.get_logger().error(f'Unknown action type: {action_type}')
            return False

    async def execute_navigate_to(self, params: Dict) -> bool:
        """
        نیویگیشن ایکشن انجام دیں
        """
        try:
            destination = params.get("destination", [0.0, 0.0, 0.0])

            # Pose میسج تیار کریں
            pose_msg = Pose()
            pose_msg.position.x = float(destination[0])
            pose_msg.position.y = float(destination[1])
            pose_msg.position.z = float(destination[2])

            # سادہ کیوں کہ ہم صرف XY ہی سمت میں جا رہے ہیں
            pose_msg.orientation.z = 0.0
            pose_msg.orientation.w = 1.0

            # گول پبلش کریں
            self.navigation_goal_pub.publish(pose_msg)

            self.get_logger().info(f'Published navigation goal to: {destination}')
            return True
        except Exception as e:
            self.get_logger().error(f'Navigation error: {str(e)}')
            return False

    async def execute_grasp_object(self, params: Dict) -> bool:
        """
        گریس ایکشن انجام دیں
        """
        try:
            object_name = params.get("object_name", "unknown")
            position = params.get("position", [0.0, 0.0, 0.0])

            # گریس سیکوئنس انجام دیں
            success = await self.perform_grasp_sequence(position)

            if success:
                self.get_logger().info(f'Successfully grasped {object_name} at {position}')
            else:
                self.get_logger().error(f'Failed to grasp {object_name} at {position}')

            return success
        except Exception as e:
            self.get_logger().error(f'Grasp error: {str(e)}')
            return False

    async def perform_grasp_sequence(self, position: List[float]) -> bool:
        """
        گریس کی مکمل سیکوئنس انجام دیں
        """
        try:
            # 1. ہاتھ کو چیز کے قریب لائیں (پری-گریس)
            pre_grasp_pos = [
                position[0] - 0.1,  # تھوڑا پیچھے سے شروع کریں
                position[1],
                position[2] + 0.05  # تھوڑا اوپر سے شروع کریں
            ]

            await self.move_arm_to_position(pre_grasp_pos)
            await asyncio.sleep(1.0)  # تھوڑا وقفہ

            # 2. چیز کی طرف سیدھا جائیں
            await self.move_arm_to_position(position)
            await asyncio.sleep(0.5)

            # 3. گریس کریں (ہاتھ بند کریں)
            await self.close_gripper()
            await asyncio.sleep(0.5)

            # 4. چیز کو تھوڑا اوپر اٹھائیں
            lift_pos = [
                position[0],
                position[1],
                position[2] + 0.1  # 10cm اوپر اٹھائیں
            ]
            await self.move_arm_to_position(lift_pos)

            return True
        except Exception as e:
            self.get_logger().error(f'Grasp sequence error: {str(e)}')
            return False

    async def move_arm_to_position(self, position: List[float]) -> bool:
        """
        ہاتھ کو مخصوص پوزیشن پر لے جائیں
        """
        try:
            # ہم یہاں ہاتھ کے جوائنٹس کے لیے IK حل استعمال کریں گے
            # اس کا نفاذ ہیومنوائڈ کے IK حل کے ساتھ ہوگا
            joint_angles = self.calculate_inverse_kinematics(position)

            if joint_angles:
                await self.send_joint_trajectory(joint_angles)
                return True
            else:
                self.get_logger().error(f'Could not calculate IK for position: {position}')
                return False
        except Exception as e:
            self.get_logger().error(f'Move arm error: {str(e)}')
            return False

    def calculate_inverse_kinematics(self, position: List[float]) -> List[float]:
        """
        مخصوص پوزیشن کے لیے معکوس کنیمیٹکس کا حساب لگائیں
        یہ ایک جگہ دار نفاذ ہے - اصل میں Isaac Sim یا کسی اور IK حل کا استعمال ہوگا
        """
        # یہ ایک جگہ دار نفاذ ہے
        # حقیقی نفاذ میں، Isaac Sim یا PyKDL کا استعمال ہوگا
        x, y, z = position

        # سادہ مثال - اسے اصل IK حل کے ساتھ تبدیل کیا جائے گا
        # یہ صرف ڈیمو کے لیے ہے
        joint_angles = [
            math.atan2(y, x),  # شاید ہپ جوائنٹ
            0.0,               # شاید کنی جوائنٹ
            0.0,               # شاید اینکل جوائنٹ
            0.0,               # شاید شولڈر جوائنٹ
            0.0,               # شاید الزو جوائنٹ
            0.0                # شاید ورسٹ جوائنٹ
        ]

        return joint_angles

    async def send_joint_trajectory(self, joint_angles: List[float], duration: float = 2.0) -> bool:
        """
        جوائنٹ ٹریجکٹری کمانڈ بھیجیں
        """
        try:
            trajectory_msg = JointTrajectory()
            trajectory_msg.joint_names = self.get_robot_joint_names()

            point = JointTrajectoryPoint()
            point.positions = [float(angle) for angle in joint_angles]
            point.time_from_start = Duration(sec=int(duration), nanosec=int((duration % 1) * 1e9))

            trajectory_msg.points.append(point)

            self.joint_trajectory_pub.publish(trajectory_msg)

            self.get_logger().info(f'Published joint trajectory: {joint_angles}')
            return True
        except Exception as e:
            self.get_logger().error(f'Trajectory error: {str(e)}')
            return False

    def get_robot_joint_names(self) -> List[str]:
        """
        روبوٹ کے جوائنٹ کے نام حاصل کریں
        """
        # یہ نام Isaac Sim ہیومنوائڈ ماڈل کے مطابق ہونے چاہئیں
        return [
            'left_hip_joint', 'left_knee_joint', 'left_ankle_joint',
            'right_hip_joint', 'right_knee_joint', 'right_ankle_joint',
            'left_shoulder_joint', 'left_elbow_joint', 'left_wrist_joint',
            'right_shoulder_joint', 'right_elbow_joint', 'right_wrist_joint'
        ]

    async def close_gripper(self) -> bool:
        """
        گریپر بند کریں
        """
        # گریپر کنٹرول کے لیے ROS 2 میسج بھیجیں
        # یہ Isaac Sim ہیومنوائڈ ماڈل کے مطابق ہوگا
        self.get_logger().info('Closing gripper')
        return True  # جگہ دار

    async def execute_place_object(self, params: Dict) -> bool:
        """
        چیز رکھنے کا ایکشن انجام دیں
        """
        try:
            position = params.get("position", [0.0, 0.0, 0.0])

            # چیز کو رکھنے کے لیے سیکوئنس
            success = await self.perform_place_sequence(position)

            if success:
                self.get_logger().info(f'Successfully placed object at {position}')
            else:
                self.get_logger().error(f'Failed to place object at {position}')

            return success
        except Exception as e:
            self.get_logger().error(f'Place error: {str(e)}')
            return False

    async def perform_place_sequence(self, position: List[float]) -> bool:
        """
        چیز رکھنے کی مکمل سیکوئنس انجام دیں
        """
        try:
            # 1. چیز کو منزل کے اوپر لائیں
            above_pos = [
                position[0],
                position[1],
                position[2] + 0.05  # تھوڑا اوپر
            ]
            await self.move_arm_to_position(above_pos)
            await asyncio.sleep(0.5)

            # 2. منزل پر لے جائیں
            await self.move_arm_to_position(position)
            await asyncio.sleep(0.5)

            # 3. گریپر کھولیں (چیز چھوڑیں)
            await self.open_gripper()
            await asyncio.sleep(0.5)

            # 4. ہاتھ کو تھوڑا اوپر اٹھائیں
            retract_pos = [
                position[0],
                position[1],
                position[2] + 0.1  # 10cm اوپر
            ]
            await self.move_arm_to_position(retract_pos)

            return True
        except Exception as e:
            self.get_logger().error(f'Place sequence error: {str(e)}')
            return False

    async def open_gripper(self) -> bool:
        """
        گریپر کھولیں
        """
        self.get_logger().info('Opening gripper')
        return True  # جگہ دار

    async def execute_speak(self, params: Dict) -> bool:
        """
        بولنے کا ایکشن انجام دیں
        """
        try:
            message = params.get("message", "")

            # TTS میسج بھیجیں
            tts_msg = String()
            tts_msg.data = message
            self.tts_pub.publish(tts_msg)

            self.get_logger().info(f'Spoken: {message}')
            return True
        except Exception as e:
            self.get_logger().error(f'Speak error: {str(e)}')
            return False

    async def execute_follow(self, params: Dict) -> bool:
        """
        پیچھا کرنے کا ایکشن انجام دیں
        """
        try:
            target = params.get("target", "person")

            # پیچھا کرنے کا کوڈ یہاں ہوگا
            # یہ ایک مستقل کنٹرول سسٹم ہوگا
            self.get_logger().info(f'Starting to follow: {target}')

            # یہ عام طور پر ایک مستقل کنٹرول سرور کو کال کرے گا
            return True
        except Exception as e:
            self.get_logger().error(f'Follow error: {str(e)}')
            return False

    async def execute_locate_object(self, params: Dict) -> bool:
        """
        چیز تلاش کرنے کا ایکشن انجام دیں
        """
        try:
            object_name = params.get("object_name", "unknown")

            # چیز تلاش کرنے کا کوڈ یہاں ہوگا
            # یہ وژن کمپوننٹ کو کال کرے گا
            self.get_logger().info(f'Starting to locate: {object_name}')

            # یہ عام طور پر ایک سرچ الگورتھم کو چلائے گا
            return True
        except Exception as e:
            self.get_logger().error(f'Locate error: {str(e)}')
            return False

def main(args=None):
    rclpy.init(args=args)

    node = ActionComponent()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        node.get_logger().info('Shutting down Action Component')
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```
